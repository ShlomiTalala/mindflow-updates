# MindFlow — live updates

Built app files only, served by GitHub Pages for the MindFlow Android app's
live updates: `latest.json` names the newest bundle, `bundles/<version>.zip`
holds it. The same files ship inside every APK. No source code, no keys, no
player data — progress and family photos never leave the phone.

Published by `npm run publish-update` in the (private) app repository.
